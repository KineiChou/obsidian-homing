# 整理、归档提示与补链交互

状态：0.2.0 开发预览。本文描述当前实现；真实宿主与服务验证范围见 [验证记录](validation.md)。名称、作者署名和许可证尚未最终确定。

## 入口与分工

| 入口 | 行为 |
| --- | --- |
| 状态栏收件箱图标与数量 | 显示可归档建议数量，点击在主区域打开收件箱整理标签页；已有标签页会被复用 |
| 收件箱整理视图 | 左侧笔记列表，右侧正文预览，下方归档操作；供集中处理 |
| 编辑器顶部归档提示条 | 当前收件箱笔记有可用归档建议时显示位置与归档按钮；不弹开整理视图 |
| 状态栏链接数量 | 仅当前笔记存在链接建议时显示，点击打开批量确认弹窗 |
| 命令面板与设置 | 打开整理、分析当前收件箱笔记、查找当前文字链接、暂停／恢复自动分析，以及服务与范围配置 |

不再使用侧栏中的“当前笔记／收件箱”双标签。恢复旧侧栏布局时迁移到主区域整理视图。后台结果不抢焦点，不弹开整理标签页或链接弹窗。命令不默认占用全局快捷键。界面跟随 Obsidian 语言，支持英语和简体中文。

## 配置与发送范围

设置分为“开始使用”“自动分析”以及折叠的范围／用量、管理区域，使用原生设置标题。

1. 搜索选择收件箱，或显式创建目录；默认包含其子目录，不修改 Obsidian 默认新建笔记位置。
2. 选择 Jev、OpenAI 兼容服务或 Anthropic。兼容服务可填写基础地址与模型；凭据用密钥引用保存。切换提供方会采用对应默认地址、模型并清除当前凭据选择。
3. 使用固定合成示例检查连接并启用本机自动分析。自动归档与自动补链分别设置，补链默认关闭。

已有收件箱笔记会显示为等待，启用自动分析不会上传历史库存。默认长文采用本地结构摘录；用户可切换为全文，超限时得到失败说明。可选目录画像默认关闭，启用后可发送候选目录内其他笔记的有限标题和标签，不能声称只发送当前笔记。

范围设置包括收件箱子目录、链接范围、完全排除路径、排除归档目标及目录用途／容器规则。每日总请求上限默认 100；自动补链另占总上限的 30%（向下取整）。范围／用量区域显示本机请求数、已知输入 token 与未知用量；不换算为服务账单。

## 集中归档

整理视图左侧按可归档、处理中、等待、已归档分组；等待组默认折叠，忽略的笔记不出现在列表。用户可勾选多篇进行分析，但移动仍逐篇确认。状态变化保留当前查看对象和操作焦点，不因后台结果自动切换笔记。

右侧使用 Obsidian Markdown 渲染当前选中笔记，提供打开原文入口。预览最多 20,000 UTF-16 单元，截断时明确提示；异步返回的旧笔记内容不能覆盖当前选择。已归档条目的预览使用移动后的路径。

底部主按钮直接显示“移到 Resources › 机器学习”等目标路径，按钮就是最终移动确认，不再增加重复确认弹窗。改选位置后先准备并展示新目标，仍须点击移动。点击“跳过”仅切换到下一篇，不忽略笔记；“更多”使用原生菜单提供忽略操作。

通常只显示一个推荐目标。当排序前两项差距较小时，操作区可提供最多两个其他目录作为快捷改选入口；不展示概率或正确率，不让用户把内部排序理解为置信度。未确定位置的笔记可重新分析或手动选择目录。

目录选择器显示完整路径。搜索无匹配且输入为允许的新路径时，提供创建入口；用户在创建弹窗核对路径后创建，随后准备该目标的归档计划。创建目录本身不移动笔记；收件箱、排除范围和不接收笔记的容器仍受规则限制。

### 成功、撤销与键盘

归档成功后自动前进到下一篇待处理笔记，并保留带原目标路径的撤销条。下一次归档有短暂防连击保护；同一计划只执行一次。最近操作也保留当前会话的撤销入口，撤销移动当前内容，不恢复旧正文。

快捷键仅作用于整理视图，输入框、输入法组词、修饰键组合和长按重复不触发：

| 按键 | 操作 |
| --- | --- |
| J / K | 下一篇／上一篇 |
| Enter | 确认当前已经准备好的归档计划 |
| E | 更改目录 |
| S | 跳过当前笔记 |
| Z | 撤销本视图最近一次仍可撤销的移动 |

重启后，已完成移动显示为已归档，不再提供跨会话撤销。未完成意图会核对两端路径和内容指纹：能确认结果时归档，无法确定才显示需核对。人工核对后可结束 review；不会重新执行移动。最近操作最多展示最近 20 条，持久化完成历史最多 100 条，未解决记录不被静默裁剪。

## 分析已有笔记

工具栏“分析”以及“分析选中项”都会先打开分析确认弹窗。弹窗展示候选笔记、正常请求次数粗估范围、剩余总额度和当前服务的发送说明。列表按修改时间倒序排列，默认勾选额度建议数量；可全选、全不选或逐篇调整。

请求预估只使用文件大小与目录元数据，不先上传正文。它不包含重试，不能视为实际费用保证。确认按钮显示篇数；没有勾选或剩余额度为零时禁用。取消不会开始分析，确认仅处理勾选且仍有效的路径，忽略、已有可用建议或正在处理的笔记会被排除。额度耗尽的待办保持等待，不批量标为分析失败。

## 编辑器顶部归档提示

当前笔记有 ready 建议时，在编辑器顶部显示归档目录和按钮，不插入正文装饰或改变光标。按钮使用已展示的计划；内容、配置或目标变化后需重新准备。与整理视图同时打开时，两处预览不应互相使对方的有效计划失效，执行后则共同失效。

移动后提示条显示目标路径与撤销入口。关闭提示只在当前插件会话隐藏该路径的提示，不删除建议、不忽略笔记，也不关闭自动分析。

## 链接批量确认

用户执行查找命令，或点击当前笔记的状态栏链接数量，打开链接建议弹窗。弹窗绑定打开时的源编辑会话；每行突出原文提及，展示局部句子、目标完整路径和勾选框，可改选候选目标。建议默认勾选，主按钮显示将添加的数量。

一次确认对同一编辑会话的有效计划使用一个原生编辑器事务；一次编辑器撤销恢复整批插入。不会写入目标笔记或另建反向链接。逐项显示应用结果与失败原因；已失效行取消勾选并禁用，不能继续提交旧锚点。异步准备或再次确认不得覆盖刚才的执行结果。

自动补链仅在编辑停顿且不处于输入法组词时分析局部脏区间，不自动弹出确认。读取快照不消耗待分析范围；只有有效结果返回或确认没有候选时，才清除对应已分析窗口。失败、超时、取消和尚未完成的请求保留未处理区间。别处输入会映射仍有效的建议，切换文件不清空其他会话结果。

撤销刚插入的链接会在当前会话抑制同位置／目标的自动推荐。手动重新查找可清除抑制；没有可靠目标时保持安静，只有主动查找才显示空结果说明。

## 异常与验证范围

普通后台结果不产生成功通知。用户操作的错误留在当前视图、弹窗或提示条；命令和初始化失败可通过宿主通知说明。移动前拒绝明显破坏引用的操作；移动后无法核实宿主链接更新时保留文件当前位置并转为需核对，不自动移回。

已在 Obsidian 1.13.7 的合成测试库验证目录选择、带入链与出链的移动及两条链接更新、移动撤销、提示条归档／撤销，以及本地模拟 HTTP 返回后的两条补链与单次原生 Undo。这不代表已评估真实模型质量、本地模型运行、真实用户知识库或所有宿主版本；完整记录以 [验证文档](validation.md) 为准。
