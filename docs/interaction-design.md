# 编辑器内归档、文件栏菜单与补链交互

状态：0.2.2 开发预览。本文描述当前实现；真实宿主与服务验证范围见 [验证记录](validation.md)。名称、作者署名和许可证尚未最终确定。

## 原则

编辑器本身就是预览。主要交互发生在用户正在阅读的笔记旁边：不打开侧栏或额外标签页，不推动正文、不抢焦点，也不遮挡输入位置。每次移动或插入仍只执行用户已经看到的计划；模型响应不能直接驱动写入。

## 入口与分工

| 入口 | 行为 |
| --- | --- |
| 编辑器右上角归档胶囊 | 收件箱笔记在编辑器右上角显示“→ 目录”。点击展开小面板，确认后归档；完成后原位提供撤销和“下一篇” |
| 正文链接提示 | 停顿后在提及文字下显示淡色虚线；悬停或光标停留时显示小卡片，可链接、换目标或忽略 |
| 文件栏右键菜单 | 原生文件栏与 Notebook Navigator 都提供单篇归档、其他目录、分析、不再建议；多选时归档或分析 N 篇；收件箱文件夹提供“整理收件箱…” |
| 整理收件箱弹窗 | 状态栏收件箱图标、命令或文件夹菜单打开；逐行显示目标位置，勾选后批量归档，或点标题逐篇打开 |
| 原生文件栏标记 | 有建议的收件箱笔记显示圆点，收件箱文件夹显示数量；可在设置中关闭 |
| 命令面板 | 整理收件箱、归档当前笔记、分析当前收件箱笔记、为当前文字查找链接、接受光标处的链接建议、暂停／恢复自动分析；默认不绑定快捷键 |

旧版的侧栏与主区域整理标签页已移除。恢复旧工作区时，遗留标签页会自动关闭。后台结果不抢焦点，不自动打开任何弹窗。界面跟随 Obsidian 语言，支持英语和简体中文。

## 配置与发送范围

设置分为“开始使用”“自动分析”以及折叠的范围／用量、管理区域，使用原生设置标题。首次尚未选择收件箱时只展开连接必需项，其余内容收在“更多设置”；首次连接成功后展开。

1. 搜索选择收件箱，或显式创建目录；默认包含其子目录，不修改 Obsidian 默认新建笔记位置。
2. 选择 Jev、OpenAI 兼容服务、Anthropic 或 Ollama。本机 Ollama 可留空密钥，远程端点需凭据。兼容服务可填写基础地址与模型；凭据用密钥引用保存。切换提供方会采用对应默认地址、模型并清除当前凭据选择。
3. 使用固定合成示例检查连接并启用本机自动分析。自动归档与自动补链分别设置，补链默认关闭。

已有收件箱笔记会显示为等待，启用自动分析不会上传历史库存。“打开收件箱笔记时分析”（默认开启，需同时开启自动归档且本机未暂停）在用户打开一篇尚无建议的收件箱笔记时，只发送这一篇；同一内容版本在本次会话中只触发一次，分析失败不会因反复打开而重试。启动时恢复的活动笔记不触发。默认长文采用本地结构摘录；用户可切换为全文，超限时得到失败说明。可选目录画像默认关闭，启用后可发送候选目录内其他笔记的有限标题和标签，不能声称只发送当前笔记。

范围设置包括收件箱子目录、链接范围、完全排除路径、排除归档目标及目录用途／容器规则。每日总请求上限默认 100；自动补链另占总上限的 30%（向下取整）。范围／用量区域显示本机请求数、已知输入 token 与未知用量；不换算为服务账单。

设置页按“开始使用／建议／显示／范围／用量与发送内容／管理”分组，全部使用原生标题；排除路径和目录用途以可删除的列表行呈现，通过“添加…”选择，不再使用多行文本框；最近移动在“管理”中以摘要显示，点“查看”打开历史弹窗，待核对记录排在最前。

“显示”分组提供两项：编辑器内链接建议（下划线／行尾标记／关闭，默认下划线）和文件栏标记（默认开启）。这两项只影响界面，不改变发送范围或已有建议。

## 编辑器内归档胶囊

胶囊只在当前笔记属于收件箱且处于待处理状态时出现，挂在笔记视图的内容容器上并绝对定位在右上角，不参与排版；源码、实时预览和阅读模式都显示，切换模式不会消失。静止时低对比，悬停或聚焦时清晰；视图窄于 520 px 时只显示图标。

| 状态 | 胶囊 |
| --- | --- |
| 有建议 | `→ 机器学习`，完整路径在提示和可访问名称中 |
| 分析中 | “准备中…” |
| 尚无建议／分析失败 | “归档…”，面板提供分析和手动选择 |
| 移动中 | “正在移动…” |
| 已归档 | “已归档到 … · 撤销 · 下一篇 · 还有 N 篇 →” |

点击胶囊，或执行“归档当前笔记”，在胶囊下方展开面板：完整目标路径、分数接近时最多两个备选目录、摘录发送说明、附件保持原位的数量，以及“归档”“其他位置…”“…”（重新分析、不再建议）。面板打开后才准备移动计划；“归档”就是最终确认，不再弹二次确认。命令打开时焦点移到“归档”按钮，Esc 关闭并把焦点还给编辑器，点击面板外关闭。

选择其他目录或备选目录只改变面板显示的目标，仍需点击“归档”。同一文件的多个窗格共享手选目标；选择器回调绑定打开时的建议，旧建议的选择不会作用于新建议。

归档成功后，胶囊原位显示结果、撤销和“下一篇”。这两个按钮有 400 ms 防连击保护，避免连续点击误操作下一篇。“下一篇”在同一窗格打开下一篇待处理笔记，优先有建议的笔记。移动会重命名同一文件对象，结果保留；切换到其他笔记后不再显示旧的撤销入口。

## 整理收件箱弹窗

弹窗是集中处理的唯一入口，替代旧整理页。

- “有建议”组：每行显示复选框、笔记标题、`→ 目标路径`和“更改”。分数明显领先的建议默认勾选；前两名相差不到 0.2 的默认不勾选，并提示“另有 N 个接近的选项”。从多选右键菜单进入时，只勾选所选笔记。
- 展开箭头显示笔记开头约 280 字的纯文本，不渲染 Markdown。
- “尚未确定”组：分析中、等待或无建议的笔记；可手动选择目录（选择后进入可勾选状态），或用“分析…”打开分析确认弹窗。
- “归档 N 篇”固定确认时的目标和笔记版本，处理中暂停改选；依次为每篇重新准备并校验计划，逐行报告结果。等待期间内容发生变化的笔记留在收件箱，提示重新选择位置；单篇失败不会中断其余笔记，也不会被报告为成功。每行成功后提供撤销。
- 点击标题会关闭弹窗并在编辑器中打开该笔记，从这里开始逐篇整理。“逐篇打开”从第一篇待处理笔记开始。

最近操作和待核对记录移到设置的“管理”区；最近一次撤销也保留在胶囊上。

## 文件栏集成

原生文件栏通过公开的 `file-menu`／`files-menu` 事件接入。Notebook Navigator 自己的菜单不触发这些事件，因此在其 API 1.2.0 及以上版本通过 `menus.registerFileMenu`／`registerFolderMenu` 接入；插件晚于本插件启用或重新加载时，在布局变化时按 API 实例重绑，并清理旧菜单注册。本插件不向 Notebook Navigator 的列表注入任何 DOM。

单篇菜单中的“归档到 X”和“归档到其他目录…”直接执行：菜单文字或目录选择器已经显示完整目标，这次点击就是确认。完成后用短通知说明目标并附撤销。多选菜单只打开整理弹窗或分析确认弹窗，不直接批量移动。

原生文件栏没有公开的装饰 API。标记通过检测内部条目表实现，找不到时不做任何事；行被延迟渲染时借助 DOM 观察补上。标记只是提示，所有操作都另有菜单和命令入口。

## 分析已有笔记

收件箱弹窗的“分析…”、多选笔记右键菜单的“分析 N 篇…”都会先打开分析确认弹窗。弹窗展示候选笔记、正常请求次数粗估范围、剩余总额度和当前服务的发送说明。列表按修改时间倒序排列，默认勾选额度建议数量；可全选、全不选或逐篇调整。

请求预估只使用文件大小与目录元数据，不先上传正文。它不包含重试，不能视为实际费用保证。确认按钮显示篇数；没有勾选或剩余额度为零时禁用。取消不会开始分析，确认仅处理勾选且仍有效的路径，忽略、已有可用建议或正在处理的笔记会被排除。额度耗尽的待办保持等待，不批量标为分析失败。

## 写作补链

自动补链只在编辑停顿且不处于输入法组词时分析局部脏区间，从不自动弹窗。建议以淡色虚线下划线呈现，不改变文字颜色；输入时立即隐去，停顿 1.5 秒后恢复，避免在打字位置闪动。选择“行尾标记”时，每行最多一个小链接图标，悬停列出该行全部建议；选择“关闭”时只在链接列表中查看。

悬停下划线 300 ms，或光标在提及内停留约 700 ms，显示小卡片：目标标题、路径和简述，以及“链接”“其他笔记…”“忽略”。卡片不获取焦点，不拦截普通点击和键盘输入；Esc、滚动或编辑会关闭卡片。键盘用户可执行“接受光标处的链接建议”（可自行绑定快捷键）。“其他笔记…”只改变卡片上的目标，仍需点击“链接”。

## 链接批量确认

用户执行查找命令，或点击当前笔记的状态栏链接数量，打开链接建议弹窗。弹窗绑定打开时的源编辑会话；每行突出原文提及，展示局部句子、目标完整路径和勾选框，可改选候选目标。建议默认勾选，主按钮显示将添加的数量。

一次确认对同一编辑会话的有效计划使用一个原生编辑器事务；一次编辑器撤销恢复整批插入。不会写入目标笔记或另建反向链接。逐项显示应用结果与失败原因；已失效行取消勾选并禁用，不能继续提交旧锚点。异步准备或再次确认不得覆盖刚才的执行结果。

自动补链仅在编辑停顿且不处于输入法组词时分析局部脏区间，不自动弹出确认。读取快照不消耗待分析范围；只有有效结果返回或确认没有候选时，才清除对应已分析窗口。失败、超时、取消和尚未完成的请求保留未处理区间。别处输入会映射仍有效的建议，切换文件不清空其他会话结果。

## 异常与验证范围

普通后台结果不产生成功通知。用户操作的错误留在胶囊面板、卡片或弹窗行内；文件栏菜单直接操作和命令失败用宿主通知说明。移动前拒绝明显破坏引用的操作；移动后无法核实宿主链接更新时保留文件当前位置并转为需核对，不自动移回。

新界面已通过自动化测试（jsdom 与真实 CodeMirror 6），以及浏览器中的明暗主题、窄编辑区样式预览。浏览器预览使用模拟控制器和近似主题变量，不等同于真实宿主验证。真实 Obsidian 与 Notebook Navigator 中的胶囊定位、菜单、文件栏标记、主题兼容和输入法行为仍待按 [验证记录](validation.md) 的清单核对。
