# 0.2.0 审阅落实

对应 [0.1.2 审阅](review-2026-09-24.md) 与 GitHub issues #1–18。本文记录本地实现和验证范围，不表示已关闭远程 issue 或完成公开发布。测试证据及未覆盖边界见 [验证记录](validation.md)。

| Issue | 当前实现 | 验证与边界 |
| --- | --- | --- |
| #1 建议失效 | 拆分归档／链接设置版本，保留无关变化后的建议；失效任务按自动开关重新等待 | 队列与宿主端口回归；历史库存不会因此自动上传 |
| #2 建议持久化 | schema 2 保存最小建议，按完整原文指纹、设置和目标离线恢复 | 单元／集成及原生连续两次重载；启动目录初始化不会清空磁盘建议 |
| #3 移动历史 | 已完成记录重启后归档，未定结果供人工核对，完成历史上限 100 | 恢复、核对与裁剪测试；撤销仅限当前插件会话 |
| #4 链接成本 | 语义缓存、局部脏区间、锚点映射，自动补链最多使用日额度 30% | 缓存、取消、重试、预算、批量撤销抑制测试；无全库正文扫描 |

| #6 移动与引用 | 运行时检查宿主自动更新链接配置，移动前检查、移动后复核解析 | 1.13.7 合成库入链／出链更新及撤销；图片、附件、歧义组合仍待补全 |

| #8 整理主界面 | 主区域标签页、分组清单、Markdown 预览、固定动作区、局部快捷键与旧视图迁移 | DOM／原生检查；异步预览、焦点和手选目录跨笔记隔离回归 |
| #9 编辑器提示条 | 当前收件箱笔记显示目录、确认、隐藏及撤销 | CM6 集成与原生归档／撤销；不自动获取编辑焦点 |

| #11 原生交互细节 | 状态栏图标及数量、Setting 标题、原生 Menu、折叠高级范围 | 原生与主题检查；目录选择不返回 thenable 控件 |
| #12 中英文 | `getLanguage()` 驱动中英文 UI、命令和错误信息 | 英文原生界面及字典测试；分类提示仍为中文，英文提示质量对照待做 |
| #13 多提供方 | Jev、OpenAI-compatible、Anthropic 共用调度与预算，严格校验返回目标 ID | HTTP 替身和本地确定性兼容服务通过；真实 OpenAI、Anthropic、Ollama 未验收 |

| #17 交互选择 | 按用户确认，不确定时显示备选，归档后自动前进；保留撤销和防连击 | UI 回归及原生检查；不展示未经校准的置信度 |
| #18 创建目标 | 无匹配时可显式确认创建允许的目录，再展示归档计划 | 路径规则、创建确认及目录刷新回调回归；原生创建后立即出现正确移动按钮 |

本轮同时修复了验证中发现的三处竞争：目录刷新使选择器回调绑定已销毁的操作区、启动目录初始化覆盖待恢复队列、设置保存未完成时连接测试使用旧配置。均由回归测试覆盖。插件热重载会重新绑定保留的整理视图，避免继续访问已销毁的协调器。
