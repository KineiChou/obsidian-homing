# 0.2.1 开发预览验证

验证日期：2026-09-24。环境：macOS arm64、Node.js 22.21.1、Obsidian 1.13.7。自动化测试使用合成内容、内存端口及模拟 HTTP；原生验收使用独立合成 vault。本轮还执行了 38 次固定合成内容的真实 Jev 对照，以及隔离 Ollama 实测；没有把用户知识库用作测试夹具。

## 自动化门禁

`npm run check` 通过：TypeScript strict、ESLint、176 项测试（17 个文件）和生产构建。评估脚本的 6 项 Node 测试另行通过。安装产物另经版本一致性检查与打包。测试覆盖：

- 建议按相关设置和内容精确失效、自动任务重排、历史库存不自动上传、schema 1 → 2、最小建议离线恢复、连续两次恢复后的磁盘记录、损坏数据拒绝。
- 已完成移动归档、未完成意图核对、人工确认核对结果、同会话撤销和完成历史上限；两个同时显示的确认计划互不覆盖，但第二次实际移动被版本校验拒绝。
- 局部脏区间只在有效分析后确认消费、无关编辑映射锚点、语义缓存、批量链接一个事务、部分过期及多批次撤销抑制；自动补链子额度与共享总额度。
- 3 万字中文结构摘录、全文超限、分类分组及决选每轮带正文、目录画像隐私开关和排除规则、短名单边界与全量回退、线性中文分词和上下文预算。
- 多提供方请求及严格目标校验、凭据变化取消在途请求、旧 401 不暂停新配置、设置保存完成后才测试连接；未用真实 API 代替替身测试。
- 实际 ReviewPanel DOM、批量分析预检、链接弹窗和设置控件：确认、取消、确切选中范围、异步预览、焦点、自动前进、防连击、目录刷新后的回调、手选目标跨笔记隔离、中英文和创建目录。
- 真实 CodeMirror 6 与标准 Markdown 解析器在 jsdom 中验证语法排除、UTF-16 偏移、事务、提示条、输入版本和销毁；插件异步初始化及视图重建期间卸载不会继续注册或抢回焦点。
- 插件重载等待旧实例的本地队列、设置及移动日志完成写入，覆盖尚未提交给 store 的微任务；新实例不等待旧 HTTP，晚到响应不覆盖新用量。卸载时未返回的已发送请求保留为未知用量。

目录选择 thenable、目录刷新后的选择回调、启动初始化清空待恢复建议都有回归测试。后两项由本轮原生验收发现；启动丢失回归在修复前失败，修复后通过。

## 编辑器内界面（feat/editor-ui，2026-09-24）

整理页与顶部提示条被编辑器胶囊、正文链接提示、整理收件箱弹窗和文件栏菜单取代。`npm run check` 通过：TypeScript strict、ESLint、181 项测试（19 个文件）和生产构建。新增测试覆盖：

- 胶囊：挂在编辑器外层且不进入正文 DOM；打开面板前不准备计划；只有“归档”移动；完成态防连击、撤销、同窗格下一篇；分屏共享手选目标、旧建议的选择被忽略；命令只在可用时打开并聚焦，Esc 关闭；重命名后保留结果、切换笔记后清除。
- 链接提示：下划线不改变文本；输入时隐藏、停顿后恢复；行尾标记与关闭档；悬停卡片的链接、换目标、忽略；“接受光标处的链接建议”只在光标位于提及内时生效。
- 整理收件箱弹窗：接近选项默认不勾选；逐篇准备与确认，单篇失败不阻断其余；改选目标先显示后归档；多选入口的预选；纯文本预览与逐篇打开。
- 文件栏：原生菜单只对收件箱笔记出现并按显示目标归档；文件夹与多选菜单；Notebook Navigator 2.0 菜单 API 注册、1.1 拒绝注册；原生文件栏标记写入与关闭后清除。
- 生命周期：遗留整理标签页在布局就绪时关闭；真实协调器与胶囊集成时，编辑后旧建议不再显示。

另在浏览器中用生产 `styles.css`、模拟控制器和近似主题变量检查了明暗主题、面板、完成态、悬停卡片、整理弹窗及窄编辑区的图标模式；发现并修复了暗色下静止胶囊对比度过低，以及“接近选项”计数偏大。这不是宿主验证。

尚待在独立合成 vault 中核对：胶囊在源码／实时预览、属性区、内联标题和滚动条旁的位置；多窗格与弹出窗口；原生文件栏标记在折叠展开、大目录和 Iconize 等插件共存时的表现；Notebook Navigator 菜单（含晚于本插件启用）；下划线与输入法组词、表格、列表缩进；键盘命令与主题（默认、Minimal）；最低版本 1.11.4。

## 固定合成模型对照

- [目录画像](folder-profile-evaluation.md)：300 个目录、7 篇固定笔记；关闭时 5/7、14 次请求、105522 输入 token，开启时 7/7、8 次、62587 token。一个歧义样例因证据不足保留全量候选，开启画像反而更贵。
- [提示语言](prompt-language-evaluation.md)：8 个成对样例，共 16 次 Jev 请求；中英文均 8/8，输入 token 分别 4745 和 4525。继续使用现有中文分类指令，避免凭小样本更改生产语义。
- [Ollama](ollama-acceptance.md)：qwen3:1.7b 4/4 协议有效，3/4 选择正确；无匹配样例误选目录，smoke 退出码 1 如实保留。此前 0.6b 的格式错误也由严格 parser 拒绝，没有为通过测试放宽校验。

上述有限样例用于协议与设计对照，不能估计真实知识库的准确率。

## 历史索引基准（0.1.2）

`node --expose-gc benchmarks/metadata-index.mjs` 导入生产 MemoryMetadataIndex，构建 20,000 篇合成笔记，每篇一个标题和一个别名；1,200 UTF-16 窗口，预热 100 次后查询 1,000 次。

| 指标 | 本机一次观测 |
| --- | ---: |
| 连续建索引 CPU 时间 | 34.87 ms |
| GC 后堆增量 | 30.59 MiB |
| 查询中位数 | 0.268 ms |
| 查询 P95 | 0.350 ms |

只测索引本身，未包含 Obsidian 元数据、编辑器、界面、网络或调度让出时间；并非整体插件内存和启动耗时。生产启动会分批让出主线程。本地匹配模块没有文件 I/O 接口。结果依设备和语料而变，不代表中文召回率或最坏情况保证。先前算法比较保留在独立 benchmark 中，不与本次生产实现测量混淆。

## 历史 Jev 冒烟（2026-09-23）

`node scripts/jev-smoke.mjs` 使用生产 JevClient，从标准输入接收密钥，不落盘；只发送脚本内固定的虚构文本。

| 场景 | 实际选择 | 返回输入 token | 本次延迟 |
| --- | --- | ---: | ---: |
| 英文连接示例 | learning，符合预期 | 318 | 698 ms |
| 中文目录：机器学习／电气 | f1 机器学习，符合预期 | 422 | 707 ms |
| 中文 Transformer 同名消歧 | n1 注意力模型，符合预期 | 415 | 432 ms |

三次均返回 jev-1.13.0，通过生产响应校验，合计 1,155 输入 token。此记录不包含密钥、账户信息或用户笔记，不作为准确率估计。

2026-09-23 使用标题为 `Study notes` 的合成对象序列化笔记复现多目录失败：384 个虚构目录形成 6 组、每组 65 个选项，其中一组概率合计 0.99，旧解析器将 HTTP 200 响应拒绝为无效。修复后再次调用，仍出现 0.99 的分组概率；生产分类器完成 6 组提名和 19 项决选，推荐对象序列化目录，共返回 23,190 输入 token。64 目录的直接分类及另一篇多主题合成笔记也通过响应校验。这验证响应兼容与分组流程，不代表真实语料准确率。

## 剩余验证与限制

1. 最低支持版本 1.11.4 未实机验证；中文 IME、源码／实时预览切换、Obsidian 私有语法、链接 redo、同名与图片附件组合、同步和外部编辑竞争仍需补齐。移动端不在本版支持范围。
2. 真实 OpenAI、Anthropic 服务没有验收。Ollama 已做小模型协议及连接检查，大候选集和长上下文未测。历史与本轮 Jev 固定例子均不构成真实语料准确率估计。
3. UI 和错误支持中英文，分类提示仍使用中文；英文对照和目录画像消融已有固定合成结果，目录画像默认关闭，其在真实笔记中的效果仍未知。
4. 大规模同步事件、完整插件内存峰值与真实语料召回率未测量。元数据匹配不读取全库正文，不提供 embedding 语义检索。词条、候选数量和上下文均有上限，可能减少覆盖。
5. 自动更新内部链接配置缺失或关闭时，移动采用保守检查；文件已移动但后置复核失败时转为需核对，保留当前位置。撤销仅限当前插件会话，跨重启不会自动重放移动。
6. frontmatter 在开头 1,200 UTF-16 单元内未闭合时不提供补链。额度为本机请求计数，预估不含重试，不等于服务商账单；无跨设备锁。
7. GitHub Actions 发布流程尚未远程执行；正式名称、作者署名和许可证按用户决定暂缓。本轮不推送外部仓库、不创建 release、不提交社区市场。
