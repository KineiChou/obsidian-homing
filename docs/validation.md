# 0.1.1 开发预览验证

验证日期：2026-09-22。环境：macOS arm64、Node.js 22.21.1。自动化测试使用合成内容、内存端口和模拟 HTTP。另按用户明确要求使用其密钥完成固定示例的真实 Jev 请求；不记录凭据、不上传用户笔记。

## 已完成

- TypeScript strict 检查、ESLint、生产构建。
- 70 项测试、7 个测试文件覆盖领域单元和宿主端口集成；具体数量由 `npm test` 输出。
- Jev 请求与响应校验、255 项上限、分组后统一决选、真实在途名额、排队取消、超时、重试、401 暂停、额度预留及未知用量。
- 收件箱范围、稳定等待、既有笔记不自动上传；持久化失败、确认只执行一次、过期拒绝、移动后保留新正文撤销、重启核对。
- 中文／Unicode 原文偏移、别名差量、候选过滤、并列跳过、局部上下文排除私密属性、目标改名和链接格式变动。
- 真实 CodeMirror 6 与标准 Markdown 解析器在 jsdom 中运行：语法排除、版本和停顿、编辑事务、模拟 undo 标记、忽略映射与销毁。
- 整个宿主协调器使用内存 Obsidian 端口，跑通“分析 → 预览 → 确认移动 → 修改正文 → 撤销”，验证启动不读正文、不联网，以及并发设置和目录删除。
- 设置页选择目录覆盖真实协调器与持久化端口，并模拟 Obsidian `Setting.then()` 的原生链式行为；覆盖连续选择、保存失败及重试。恢复旧回调时两个回归测试均失败，修复后通过。
- 实际 ReviewPanel DOM：一次确认、改选、异步预览竞争、背景更新不抢焦点、不改变模式、不确定项折叠。
- 浏览器手动核对实际 ReviewPanel，320 px 侧栏、长中文路径、归档和链接确认。预览使用模拟控制器与主题变量，不能等同真实 Obsidian 主题测试。
- 独立临时目录执行 npm 11 `ci --ignore-scripts` 成功，依赖审计当时为 0 vulnerabilities。

## 实际索引基准

`node --expose-gc benchmarks/metadata-index.mjs` 导入生产 MemoryMetadataIndex，构建 20,000 篇合成笔记，每篇一个标题和一个别名；1,200 UTF-16 窗口，预热 100 次后查询 1,000 次。

| 指标 | 本机一次观测 |
| --- | ---: |
| 连续建索引 CPU 时间 | 34.87 ms |
| GC 后堆增量 | 30.59 MiB |
| 查询中位数 | 0.268 ms |
| 查询 P95 | 0.350 ms |

只测索引本身，未包含 Obsidian 元数据、编辑器、界面、网络或调度让出时间；并非整体插件内存和启动耗时。生产启动会分批让出主线程。本地匹配模块没有文件 I/O 接口。结果依设备和语料而变，不代表中文召回率或最坏情况保证。先前算法比较保留在独立 benchmark 中，不与本次生产实现测量混淆。

## 真实 Jev 冒烟验证

`node scripts/jev-smoke.mjs` 使用生产 JevClient，从标准输入接收密钥，不落盘；只发送脚本内固定的虚构文本。

| 场景 | 实际选择 | 返回输入 token | 本次延迟 |
| --- | --- | ---: | ---: |
| 英文连接示例 | learning，符合预期 | 318 | 698 ms |
| 中文目录：机器学习／电气 | f1 机器学习，符合预期 | 422 | 707 ms |
| 中文 Transformer 同名消歧 | n1 注意力模型，符合预期 | 415 | 432 ms |

三次均返回 jev-1.13.0，通过生产响应校验，合计 1,155 输入 token。此记录不包含密钥、账户信息或用户笔记，不作为准确率估计。

## 尚未验证与当前限制

1. 已验证 jev-1.13.0 可用及线上响应结构；三个固定示例不能代表中文／混合语言真实语料质量或费用估计。
2. 已在 Obsidian 1.13.7 启用插件并完成原生 Keychain 关联。目录选择回调曾把 `Setting` 返回 Promise，触发重复 thenable 解析及主线程卡死；0.1.1 将该回调明确限定为 void。仍需专用测试 vault 核对源码／实时预览、自定义语法节点、多窗格、中文输入法、主题和实际 undo/redo。
3. 移动采用保守引用检查。显式旧路径入链、相对出链解析变化、同名歧义或缓存不全会被拒绝；不依赖未公开的链接更新开关。真实宿主常见链接、图片和附件组合仍需核对。
4. 目录改名当前处理受影响子树，但大规模同步风暴尚未专门测压；非真实知识库内存峰值仍需测量。
5. 跨重启移动只供核对；同一会话提供可校验的撤销。历史记录不会自动重放。
6. 词条为 2–64 UTF-16 单元，最多 32 aliases、8 tags、160 字短描述；超限或候选并列会减少覆盖。尚无覆盖受限专用提示、单字术语开关、候选正文补充或全库语义搜索。
7. frontmatter 在开头 1,200 单元内未闭合时，整篇不提供链接建议；此时仍可使用 Obsidian 原生链接功能。
8. 无跨设备锁、不自动估算账单、不公开发布；发布名称与许可证尚未决定。
